06 / 设计原则

输入只问一次「本地文件 / 网络流」分段切换常驻 Source 区；网络流只要求一个地址，协议由前缀与扩展名自动判定，识别结果是只读徽标而非控件。不提供传输、缓冲、认证、超时、重连或窗口行数设置——这些参数与「看帧」这件事无关。切到实时流后，时长变 LIVE、指标换成帧数/关键帧、主按钮变「解析」、提示条与状态栏同步切换语义。
一个主色，且只在关键处黄铜琥珀占视觉权重约 10%：主按钮、激活 Tab、I 帧、焦点、警告。其余全部退到暖调石墨中性色。
层级靠分区，不靠卡片堆叠用表面明度差 + 1px 细分隔线建立 4 级深度（底 / 下沉 / 面板 / 抬升），避免「万物皆卡片」。
数字是主角所有表格数值等宽、右对齐、tabular-nums；指标数值 20px；表头用 UI 字体以区分「标签」与「数据」。
不单靠颜色传达信息帧类型同时有字母 + 边框 + 底色；流类型同时有文字 + 顶边色 + 编号色；状态同时有圆点 + 文案。
渐进披露长篇操作说明从表格上方移入底部状态栏；警告条可关闭；帮助按需展开。
AA 可访问性正文对比度 ≥ 4.5:1，组件边框 ≥ 3:1；焦点态在所有可交互控件上可见；无闪烁与无限动画。
交互提示：切换「视频 / 音频」标签、在表格上拖出矩形选区、试一下过滤框和「复制选区」。设计规范页含完整色板与对比度数据。
